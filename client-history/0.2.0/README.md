# Client 0.2.0

First GitHub updater release for Lineage 2 Prominence. Includes the same 1,504 managed client files and 18 cumulative patches as the validated 0.1.2-local package. The launcher now checks this repository for signed client updates. Existing INI settings are preserved. Close Lineage II before clicking Install / Update. The default server address is 127.0.0.1 for local testing; remote server connectivity is configured separately.

Initial cumulative patches relative to the original client.
