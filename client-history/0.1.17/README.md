# Client 0.1.17

Jobs and character loading
- Jobs now uses one flat list. Locked base classes stay concealed, and learned promotions appear directly.
- Unlocking a first promotion hides its original base row immediately. Saved progress is preserved.
- Double-click a Ready job to switch in town; the current job is named below the list.
- Corrected Jobs list mouse input and scrolling.
- Fixed character loading for older job histories that skip intermediate classes, and prevented failed loads from entering the world partially initialized.

Display and controls
- Alt+Enter cycles through Windowed, Borderless and Fullscreen modes.
- Windowed mode remembers its previous size, including after relaunch.
- Borderless fills the current monitor and keeps the cursor free while switching applications.
- Added a borderless fallback when Windows rejects exclusive fullscreen, and corrected overlapping device changes during repeated display-mode switches.


Compared with 0.1.16.
