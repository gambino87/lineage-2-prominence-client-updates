# Client 0.1.2

Dark Flare Visual Update

- Dark Flare now erupts in purple-to-white dark fire, with revised impact bursts, a shockwave ring, and arcing flames.
- The effect retains its existing animation, shape, and timing. Spell behavior is unchanged.

Close Lineage II and update through the launcher before reconnecting.
